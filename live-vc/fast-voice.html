What model is this?

This is a causal LLVC-style streaming student model trained from an RVC teacher, published by HEVoicechanger under GPL-3.0. It is genuine neural speech-to-speech conversion, but it is not an ordinary RVC checkpoint and cannot directly use most RVC voice downloads.

The 13.7 MB model passed a real ONNX Runtime Web WASM test on a Linux CPU. ChromeOS performance and voice quality may differ. It processes 16 kHz mono, so audio fidelity will be lower than 48 kHz RVC.
