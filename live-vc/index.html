What this mode can and cannot do

Live DSP: changes the sound of your microphone in real time with granular pitch and tone processing. A preset is not a trained person's voice. This is a working first step, not a substitute for neural RVC.
RVC: a trained neural model changes voice identity. The lab below runs actual RVC model inference on a recording, but the currently available browser pipeline is not a persistent low-latency live RVC engine.

For best results, test with headphones and ChromeOS Chrome. A low-powered processor may crackle under heavy multitasking.

02 · ACTUAL AI VOICE CONVERSION

RVC model test in your browser

EXPERIMENTAL · RECORDING

Real ONNX ContentVec → RMVPE → RVC generator inference entirely on your device, using the open-source rvc-web-runtime engine. This is not real-time yet. The current runtime reloads model sessions per conversion, so using it directly for a continuous live call would add huge lag.

Want a voice model to try? Licensed experimental RVC ONNX voice packs are available. Compatibility with this runtime is unverified. RVC models are speaker-specific; importing a reference MP3 alone does not train one. The common models are large and may exceed an 8 GB browser's available memory.
Upload an RVC ONNX checkpoint and a short source recording. ContentVec and RMVPE can be uploaded or downloaded. Nothing is sent to an inference server.
Download converted WAV
The model files must be real and compatible. Model downloads and JavaScript libraries need internet once; inference runs locally. On an 8 GB Chromebook the three-model RVC pipeline may run slowly, exhaust memory, or fail. If that happens the page reports the error without pretending that a pitch-shifted file was neural RVC.
