Pocket Studio diagnostics

Checks whether the real browser inference files, model metadata and audio APIs can be reached. A green result proves the resource exists, not that your machine can run full voice synthesis. No microphone audio is uploaded during these checks.

Click Run checks to test your browser and hosted model resources.

If Pocket remains stuck:

Open the full Studio, choose a built-in voice and test typed speech. First-time model downloads can take time, particularly with limited RAM. If model downloads or WASM runtime fail, disable strict network blocking for the trusted model hosts, or try recent Chrome/Edge and reload the page. Browser microphone dictation may require its own speech-recognition service.
