How it works

  1. In Pocket Studio (right/below), upload or record a reference voice, or select a built-in voice.
  2. Wait for real ONNX model loading, select a voice, then use the microphone or type a phrase.
  3. When a phrase is recognized, this page injects the actual transcript into the same-origin Pocket Studio and clicks the real Generate button.
  4. Listen to the generated stream and use Studio’s replay/WAV/MP3 controls.

Privacy: Pocket synthesis and voice samples are processed locally in the browser. Your browser’s Web Speech recognition service may process spoken audio online. For entirely local recognition, use the native Pocket Windows studio with Whisper. Model weights download on first use.

Audio feedback: Use headphones. Speaker playback can be re-captured by an open microphone; the demonstration pauses listening during synthesis.
