01 · Test online

Open an available hosted model demo or run Pocket ONNX in your browser. Record a short sample and compare the output quality.

02 · Download launcher

Get the Windows EXE from GitHub Actions, then install only the engines you want. Each model has its own dependency environment.

Run the upstream engine, import your voice and route output to speakers or a virtual audio cable.
